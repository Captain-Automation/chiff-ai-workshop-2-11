# חיבור טופס הנרשמים ל-Google Sheets (בערך 2 דקות)

בסוף התהליך תקבלו כתובת אחת. שולחים אותה אליי, ואני מכניס אותה לדף.

> אם Google אצלכם בעברית, שמות הכפתורים יופיעו בעברית. המיקום שלהם זהה.

## 1. יוצרים גיליון
1. נכנסים ל-[sheets.new](https://sheets.new). נפתח גיליון חדש.
2. נותנים לו שם למעלה, למשל: **נרשמים לסדנה 2.11**.

## 2. פותחים את Apps Script
1. בתפריט העליון לוחצים **Extensions** (תוספים) ← **Apps Script**.
2. נפתחת לשונית חדשה עם קוד קצר.

## 3. מדביקים את הקוד
1. מוחקים את כל מה שכתוב שם.
2. פותחים את הקובץ `setup/Code.gs`, מעתיקים **הכול**, ומדביקים.
3. לוחצים על אייקון השמירה 💾 (או Ctrl+S).

## 4. פורסים כ-Web app
1. למעלה מימין לוחצים **Deploy** (פריסה) ← **New deployment** (פריסה חדשה).
2. ליד **Select type** לוחצים על גלגל השיניים ⚙️ ובוחרים **Web app**.
3. ממלאים:
   - **Execute as** (ביצוע בתור): **Me** (אני)
   - **Who has access** (למי יש גישה): **Anyone** (כל אחד)
4. לוחצים **Deploy**.

## 5. מאשרים הרשאות (רק בפעם הראשונה)
1. לוחצים **Authorize access** ובוחרים את החשבון שלכם.
2. אם מופיע מסך "Google hasn't verified this app": לוחצים **Advanced** ← **Go to ... (unsafe)**.
   זה תקין. זה הקוד שלכם, בגיליון שלכם.
3. לוחצים **Allow**.

## 6. מעתיקים ושולחים
1. מופיעה **Web app URL** שמסתיימת ב-`/exec`.
2. לוחצים **Copy** ושולחים לי את הכתובת.

זהו. 🎉

### בדיקה קטנה (לא חובה)
פותחים את הכתובת בדפדפן. אם רואים `"ok":true` הכול עובד.
אחרי שהכתובת בדף, כל מי שממלא את הטופס יופיע בלשונית **נרשמים** בגיליון.

### מה יש בגיליון
תאריך ושעה · שם מלא · טלפון · אימייל · אישור דיוור (כן/לא) · דף מקור · דפדפן · מזהה · **שולם**

- מי שממלא את הטופס עוד לא בהכרח שילם. את עמודת **שולם** ממלאים "כן" לפי התשלומים ב-Invoice4U.
- מי שנרשם פעמיים מתעדכן באותה שורה. אין כפילויות.
- דיוור שיווקי שולחים רק למי שכתוב אצלו "כן" באישור דיוור.

### אם משנים את הקוד בעתיד
**Deploy** ← **Manage deployments** ← ✏️ ← בשדה Version בוחרים **New version** ← **Deploy**.
הכתובת נשארת אותה כתובת.
